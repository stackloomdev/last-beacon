# 需求与迭代方向

以下是整理后的制作需求，便于理解开发方向；它不是虚构的 one-shot 原始 Prompt，也不是逐字对话全文。

## 核心需求

制作一款用于向 Awesome GPT-6 Astra 游戏清单投稿的原创浏览器塔防。题名《最后的灯塔 / Last Beacon》。玩家守护海岛中央的灯塔，使用有限零件布置防御设施，并通过供电网络连接炮塔。

第一版包含一张精心设计的地图、单体炮塔、范围炮塔、减速塔和中继站，十波敌人与一个 Boss，以及建造、升级、出售、胜负、重新挑战等完整操作。采用微缩景观风格，以岩石岛屿、暖色灯塔和可见的电网连接建立视觉辨识度。

浏览器直接游玩，无需账号或 API Key。保留源码、运行说明及真实模型参与记录。

## 实现约束

- 建在用户指定的 `/Users/pengju/workspace/lpj` 目录下的独立项目。
- 供电必须影响真实战斗，拆除中继应让下游立即断连。
- 使用原生 Canvas 2D 和程序化素材，不依赖 CDN 或资源下载。
- 使用 Web Audio 合成音效，并由用户点击后开启。
- 初始界面使用中文，后续按创作者要求增加中英文即时切换与语言偏好保存；提供清晰的键盘操作和移动端布局。
- 规则与绘制分离，以便运行真实预算的十波战役回归。
- 支持构建静态站点以及可以直接打开的单文件 HTML。

## 验证重点

验证供电重算、容量分配、不能重复退款、暂停冻结全部战斗计时、波次不会重复结算、Boss 和胜负流程，以及桌面和手机上的建造入口与按钮可达性。

# Last Beacon · 最后的灯塔

一座灯塔，一张电网。守住最后一束光。

在线试玩：[last-beacon.loupengju.cc](https://last-beacon.loupengju.cc) · 公开源码：[stackloomdev/last-beacon](https://github.com/stackloomdev/last-beacon)。

**Last Beacon** 是一款可直接在浏览器中玩的原创三维海岛塔防。炮塔需要通过其他设施或中继站连接到灯塔；有限的电力容量决定哪些设施能够开火。建造、连线、升级，在十波机械生物的进攻中守护海岸，最后迎战深渊巨像；胜利后还可以进入无尽潮汐。

- 基于 Three.js 的实时三维海岛：带沙滩、礁崖和滑道的地形，会起伏、在岸边碎成白沫的海面，旋转光束会扫过海岛与海面的灯塔，软阴影、环境反射与泛光。
- 昼夜与天气随波次推进：黄昏渐入黑夜，第八波风暴来袭（降雨、闪电、湿润反光的地面、翻涌的海浪），深渊巨像带来血色暗夜，胜利时迎来黎明与烟花。
- 四种防御设施：哨戒炮、迫击炮、寒潮塔、电弧塔（在敌群间连锁放电）；每座炮塔可切换索敌方式：最前、最强、最近。
- 中继站、电网容量与自动连接；电缆在设施之间垂挂，供电时有能量脉冲流动。出售设施会立即重新计算下游供电。
- 灯塔技能：超频（射速提升 80%）与灯塔聚光（选定落点，蓄能后范围重击并致盲敌人）。
- 十波敌人与最终 Boss，裂殖体倒下时会分裂成幼体；胜利后可继续挑战逐波增强的无尽潮汐。
- 轻松 / 标准 / 困难三档难度，标准难度保持原版数值；三级升级、出售、暂停与双倍速。
- 可旋转、缩放、平移的镜头；高 / 中 / 低三档画质，另有 2D 视图。设备不支持 WebGL2 时自动改用 2D。
- 程序生成的海岛、建筑、机械生物、特效与合成音效（海浪、风雨、雾号、雷声，按画面位置立体声定位），无第三方游戏素材。
- 中英双语界面，适配桌面和手机；键盘和指针均可操作建造基座。
- 免费，无需登录、API Key、后端、安装依赖或外部资源。Three.js 已随仓库内置，不走 CDN。
- 各难度的最高抵达波次、通关与无尽纪录仅保存在当前浏览器。刷新会开始新的一局。

## 本地试玩

需要 Node.js 20 或更高版本。无需 `npm install`。

```sh
npm run dev
```

打开 <http://localhost:4173>。若端口被占用，可使用 `PORT=4174 npm run dev`。在网址后加 `?view=2d` 可直接使用 2D 视图。

点击右上角 **中 / EN** 切换语言。首次打开时跟随浏览器的中文或英文偏好，其他语言默认显示中文；手动选择后会在当前浏览器中记住。切换不会重开游戏，当前波次、布防、资源、选中设施和暂停状态均保留。界面、玩法说明、提示、结算与基座的辅助阅读标签都会同步切换，单文件版同样支持。

战场右上角的 **画质** 按钮在高、中、低和 2D 之间切换，选择会被记住。高画质开启泛光与灯塔光束阴影；手机默认使用中画质。

## 离线版与静态部署

```sh
npm run build
```

- `dist/` 是可部署至任意静态站点托管服务的网站。支持放在子目录中。
- `dist/last-beacon.html` 是完整单文件版（约 1 MB，其中 Three.js 约 740 KB），可下载后直接用现代浏览器打开。CSS、逻辑、Three.js、绘制代码和合成音效全部内嵌，没有 CDN 或网络依赖。
- 声音默认关闭，点击右上角音符按钮开启。

部署到 Vercel 时导入本仓库，Root Directory 保持 `./`。仓库中的 `vercel.json` 已指定静态站点预设（Other）、构建命令 `npm run build` 和输出目录 `dist`，会覆盖控制台中的对应设置。无需环境变量。若此前出现找不到 `public` 的错误，请部署包含该配置文件的最新 `main` 提交。

`vendor/three.module.min.js` 由 `node scripts/vendor-three.mjs` 从 npm 上的 three@0.186.1 打包压缩而来（仅维护者更新版本时需要联网运行），许可证见 `vendor/THREE-LICENSE.txt`。

## 如何游玩

1. 初始获得 180 零件和一座免费哨戒炮（轻松 220 / 困难 160）。
2. 选择底部设施，再点击岛上的空基座建造。悬停或键盘聚焦基座可预览射程、供电连线和设施虚影。
3. 发光的电缆脉冲表示已连接电网。停机设施上方会显示 `!`。
4. 灯塔连接距离为 3.5 格，普通设施为 3 格，中继站为 4.8 格。连接按两端较远的连接距离判断。
5. 连接成功且剩余容量足够的设施才开火。按建造顺序分配电力；断开的设施不占容量。即使因容量不足而停机，设施仍能传导连接。
6. 点击已有设施可升级、出售或切换索敌方式。升级会增加 1 点电力消耗；最高三级，电弧塔每级多跳跃一个目标。出售返还实际投入的 70%，起始免费炮塔的基础退款为零。
7. 电网可扩容四次，每次增加 6 点容量；无尽潮汐中最多可扩容十次。
8. 手动开始每一波。清除前九波后，获得补给、1 点容量并修复 5 点灯塔完整度。准备阶段不会自动出兵。
9. 战斗中可开启超频：射击频率提升 80%，持续 6 秒，冷却 35 秒。可以在战斗中建造和升级。
10. 战斗中可呼叫灯塔聚光：选择落点后，灯塔在 0.8 秒蓄能后重击 1.35 格范围并致盲敌人；伤害随波次提升，冷却 45 秒。
11. 让灯塔坚持到第十波结束。漏过的敌人会扣除完整度，深渊巨像抵达灯塔会直接摧毁它（轻松难度下改为造成 75 点损伤）。胜利后可以进入无尽潮汐，每五波出现一次深渊巨像。

通常一局约 8–12 分钟（包含建造和思考时间）；战斗本身因布阵、漏怪、减速和倍速而变化。

| 操作 | 按键 / 手势 |
| --- | --- |
| 选择哨戒炮 / 迫击炮 / 寒潮塔 / 中继站 / 电弧塔 | `1` / `2` / `3` / `4` / `5` |
| 开始下一波 / 暂停战斗 | `Space` |
| 灯塔聚光（再按一次自动瞄准最前方敌群） | `F` |
| 灯塔超频 | `O` |
| 切换选中炮塔的索敌方式 | `T` |
| 旋转视角 / 缩放 | `Q` `E` 或方向键 / `+` `−`，拖动旋转、滚轮或双指缩放 |
| 平移视角 | 右键或 `Shift` 拖动，双指拖动 |
| 取消建造、瞄准或选择 | `Esc` |
| 显示电网 | `G` |
| 开关声音 | `M` |
| 聚焦可操作控件 / 激活控件 | `Tab` / `Enter` |

切换到其他标签页会自动暂停正在进行的战斗并静音环境声，返回后手动继续。打开玩法或重开弹窗时会暂停，关闭后恢复原状态；难度在「重新出发」弹窗中选择。手机布局将建造卡放在战场下方，指挥面板位于其后；在战场上竖向滑动仍可滚动页面，横向拖动旋转视角。系统开启「减少动态效果」时，会跳过开场运镜并关闭镜头震动。

## 文件结构

```text
index.html          语义界面、帮助与结算弹窗
src/game.js         独立于浏览器的确定性战斗、电网、技能与难度规则
src/3d/world.js     Three.js 战场：同步游戏状态、拾取、事件特效与渲染
src/3d/terrain.js   海岛高度场、地形着色、射程与焦痕投影、植被分布
src/3d/water.js     海浪、岸边白沫与深浅水色
src/3d/sky.js       天空、昼夜与天气氛围、环境反射
src/3d/models.js    灯塔、设施、机械生物和场景的程序化模型
src/3d/effects.js   粒子、碎片、闪电光带、冲击环、雨与奖励文字
src/3d/camera.js    镜头旋转、缩放、平移、开场运镜与震动
src/3d/post.js      高画质泛光后期
src/render.js       Canvas 2D 等距绘制（2D 视图与自动回退）
src/app.js          建造交互、快捷键、界面、画质与本地纪录
src/i18n.js         中英文文案、语言检测与偏好保存
src/audio.js        Web Audio 合成音效与环境声
src/style.css       桌面与手机布局
vendor/             内置的 Three.js 与许可证
scripts/            维护脚本（重新生成内置的 Three.js）
server.mjs          无依赖本地静态服务器
build.mjs           静态目录与单文件离线构建（按模块图打包）
tests/              规则、双语、构建和完整战役回归
```
